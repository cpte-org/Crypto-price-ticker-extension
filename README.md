# Just Price Ticker

One coin's USD price in your browser toolbar. No trend colors, charts, accounts, tracking, or settings. Hover for the full provider price and timestamp; click to request a refresh. The badge shows `?` if a current quote cannot be confirmed, then retries automatically.

[Website](https://cpte-org.github.io/) · [Downloads](https://github.com/cpte-org/Crypto-price-ticker-extension/releases) · [Installation](https://cpte-org.github.io/install.html)

## Develop

Requires Node.js 22 or newer and npm.

```sh
npm ci
npm run check
npm run preview
```

`npm run check` runs tests, builds all packages and the website, then validates every archive, logo and local page link. Builds use the committed catalog and local logos: no live coin ranking or asset service is consulted. Dependency installation requires the npm registry.

- `extension/`: shared price runtime; no coin-specific source copies.
- `catalog/coins.json`: coin IDs, local logo provenance, Firefox IDs and Chrome distribution state.
- `catalog/market-snapshot.json`: dated market data for the curated coin selection.
- `catalog/stablecoins.json`: pinned stablecoin exclusion list; `catalog/products.json`: product tabs and verified store links.
- `assets/brand/`: the original CPTE logo, used by the website.
- `assets/logos/`: current downloaded coin logos, committed locally.
- `scripts/`: catalog validation, packaging, website generation and Chrome publishing.
- `site/`: static website assets; HTML is generated by `scripts/site.js`. Three product tabs cover Just Price Ticker, extOS and Multi-Coin Monitor. The existing extOS detail/privacy pages remain in the Pages repository.
- `tests/`: runtime failure/recovery and distribution invariants.
- `dist/packages/`: generated Chrome and unsigned Firefox ZIPs, catalog and SHA-256 checksums.
- `dist/extensions/<coin>/<browser>/`: unpacked builds for local browser testing.
- `dist/site/`: generated GitHub Pages website.

The build generates the coin configuration in memory. `extension/coin.js` is deliberately absent from source. Old Python builders, remote logo cloning, prebuilt binaries and obsolete documentation were removed; Git history preserves them.

## Behavior

Prices come directly from CoinGecko's public `/simple/price` endpoint. No private API key is embedded. The extension requests only `storage`, `alarms`, and access to `https://api.coingecko.com/*`.

A recurring one-minute alarm drives updates while the browser runs. Rate limits and outages trigger bounded exponential backoff, respecting `Retry-After` within a 15-minute ceiling. State survives background-worker restarts. Quotes older than five minutes, invalid prices and malformed responses never appear as current. The tooltip retains the last valid quote with its provider timestamp. Requests time out after 12 seconds, including response-body reads.

Chrome may delay alarms during sleep; the ticker refreshes after waking. A public API has no availability guarantee. This implementation makes failure explicit and recovers when valid data returns; it does not promise uninterrupted live prices. Multiple installed coin tickers make separate requests and may share an IP rate limit.

## Browser smoke test

```sh
BROWSER_BINARY=/path/to/extension-capable-chromium npm run test:browser
```

This optional integration test launches a fresh temporary browser profile, loads the built Bitcoin extension, verifies initial API behavior, injects rate-limit/offline responses, checks recovery, and restarts the browser to verify saved backoff. It never uses your personal browser profile. It was exercised with Brave (Chromium); stable branded Chrome may restrict command-line extension loading. Firefox browser execution is a separate manual check.

## Distribution

Exactly ten coins are eligible for Chrome Web Store uploads: Bitcoin, Ethereum, Zcash, Solana, Polygon (POL), Polkadot (DOT), Dogecoin, Avalanche (AVAX), Cardano and NEAR. This leaves the user's unrelated extension outside all ticker tooling.

The curated catalog contains 32 popular cryptocurrencies, including those fixed targets. Stablecoins, Figure Heloc, WhiteBIT Coin, Rain, LEO Token, Canton and Monero are excluded. Selection and market data are reviewed deliberately; they never change during an ordinary build. Current logos were downloaded from CoinGecko's image URLs on 2026-09-22, with individual provenance and checksums.

Firefox packages are **unsigned development builds**, loadable temporarily through `about:debugging`. There is no AMO publication or signing workflow. Permanent installation in ordinary Firefox requires Mozilla signing. These new development IDs do not replace historical signed extensions.

See [release and publishing instructions](docs/RELEASING.md) for store setup, artifact publishing and website synchronization. All ten Chrome targets appear in the store section; all ten use the normal Add to Chrome buttons, including listings awaiting approval. Four existing Opera listings appear below the ticker catalog; extOS and KDE have their own product tabs. External links open in new tabs. The owner confirmed Bitcoin is listed and pending Chrome review. NEAR has been submitted manually under `inpjbnddnhkoagnddjniomhnfandjkfa` and is also pending review. Automated publishing setup is deferred.
