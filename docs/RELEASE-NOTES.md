Just Price Ticker 4.0.0

- Price only: no trend colors, flashing, toggle or tracking.
- Automatic retry, persisted backoff and explicit unavailable/stale state.
- Updated local logos and a single catalog covering 32 curated non-stablecoins including the ten fixed Chrome targets.
- Product navigation for browser tickers, extOS browser Linux and the KDE Multi-Coin Price Monitor; four Opera listings included.
- ZIPs are named `<coin>-chrome.zip` and `<coin>-firefox.zip`; verify them with SHA256SUMS.
- Chrome ZIPs support unpacked installation. Firefox ZIPs are unsigned development builds, for temporary installation via about:debugging. No Firefox store publication or signing is performed.
- New Firefox development IDs do not update historical signed installations.

See https://cpte-org.github.io/install.html for installation instructions. GitHub builds require manual updates.
