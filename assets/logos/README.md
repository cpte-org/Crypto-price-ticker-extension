# Coin logos

Downloaded on 2026-09-22 from the current image URLs returned by CoinGecko's market-data API and normalized to 256×256 transparent PNG canvases. These are downloaded coin assets, not AI-generated marks. Each source URL, retrieval date and normalized-file SHA-256 is recorded in `catalog/coins.json`.

Logos identify their respective coins. Their trademarks and artwork remain the property of their respective owners; the repository's source-code license does not grant trademark rights. Keep provenance when replacing an image. Some unchanged official marks naturally retain older source timestamps; the downloads are fresh.

The normal build uses only these committed files and generates 16, 32, 48, 64 and 128 pixel icons. It does not contact a logo service.
